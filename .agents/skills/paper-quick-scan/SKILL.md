> **语言要求：所有输出内容必须使用中文。** 包括标题、分析、总结、评价等全部文字输出。论文中的专业术语首次出现时用「中文（English）」格式标注，后续可直接使用中文。图表编号、公式、参考文献等学术规范内容保持原文格式。

# 论文泛读 — 快速扫描（6步，约10分钟）

## 适用场景

- 每周浏览新文献时，快速判断一篇论文是否值得精读
- 大量文献初筛，决定优先级
- 只需要了解论文大意，不需要深入细节

## 使用方式

用户提供以下任一输入：
- 论文 PDF 文件
- 论文标题 + 摘要
- 论文的网页链接

然后依次执行以下 6 个步骤。

---

## 执行步骤

### 步骤 1：三句话概括

快速阅读论文（重点看标题、摘要、引言首段和结论），用**三句话**概括：
1. 这篇论文研究了什么？
2. 用了什么方法？
3. 得出了什么结论？

输出格式：
```
📌 三句话概括：
1. [研究主题与目的]
2. [研究方法]
3. [核心发现/结论]
```

### 步骤 2：一句话检验

用**一句话**向一位非专业读者介绍这篇论文。这句话应该能让一个外行明白这篇论文在做什么、为什么重要。

输出格式：
```
💡 一句话：[用通俗语言概括全文]
```

### 步骤 3：章节结构

列出论文的**主要章节标题**和**小节标题**，简要说明每个章节的大致内容。

输出格式：
```
📂 章节结构：
- 1. [章节名]：[一句话说明]
  - 1.1 [小节名]：[一句话说明]
  - ...
- 2. ...
```

### 步骤 4：核心创新点

基于对标题、摘要和章节结构的理解，判断这篇论文**最核心的创新点或贡献**可能是什么。指出 1-3 个创新点。

输出格式：
```
⭐ 核心创新点：
1. [创新点1]
2. [创新点2]（如有）
3. [创新点3]（如有）
```

### 步骤 5：关键词图谱

列出 **5-10 个关键词**，简要解释它们在这篇论文中的重要性。

输出格式：
```
🏷️ 关键词图谱：
1. [关键词] — [在这篇论文中的含义/角色]
2. ...
```

### 步骤 6：图表速览

**第一步：整理全部图表名称。** 逐一列出论文中所有图表的编号和完整标题，按出现顺序排列，并标注类型（图/表）和所在页码或章节。图表标题必须同时保留原文标题并提供完整、准确的中文翻译；不得只翻译关键词，也不得用中文翻译替代原文标题。

**第二步：重要性排序。** 将全部图表按重要性重新排序，对排名前 3 的图表描述各自传达的核心信息。Top 3 中的图表标题必须采用“原文标题（中文翻译）”格式。

**第三步：故事线判断。** 回答：仅通过看这些图表，能否还原出这篇论文的主要故事线？

输出格式：
```
📊 图表速览：

一、图表名称清单：
| 编号 | 类型 | 原文标题 | 中文翻译 | 所在章节/页码 |
|------|------|----------|----------|--------------|
| Fig. 1 | 图 | [完整原文标题] | [完整中文翻译] | [章节/页码] |
| Fig. 2 | 图 | [完整原文标题] | [完整中文翻译] | [章节/页码] |
| Table 1 | 表 | [完整原文标题] | [完整中文翻译] | [章节/页码] |
| ... | ... | ... | ... | ... |

二、重要性排序（Top 3）：
1. [图表编号+原文标题（中文翻译）] — [核心信息]
2. [图表编号+原文标题（中文翻译）] — [核心信息]
3. [图表编号+原文标题（中文翻译）] — [核心信息]

三、故事线判断：
能否通过图表还原故事线：[是/否，简要说明]
```

---

## 输出方式

- 默认直接在对话中完整展示全部分析，不生成或保存 Markdown、Word、PDF 等报告文件。
- 不能用报告链接、附件或简短摘要替代完整的对话正文；图表清单、翻译、排序及结论也必须在对话中展示。
- 内容较长时，按步骤分段连续展示，不因篇幅而省略必需模块，也不改为文件交付。
- 仅当用户明确要求导出或保存时，才生成其要求的报告文件。
- 阅读论文所需的文本提取、页面渲染等中间文件不属于报告文件；需要落盘时遵循用户指定的中间文件目录。

## 输出模板

完成全部 6 步后，按以下结构直接在对话中展示完整泛读分析。模板中的代码围栏仅用于说明结构，实际输出应正常渲染正文、列表与表格：

```markdown
# 📖 论文泛读分析

**论文标题**：[标题]
**作者**：[作者列表]
**发表时间**：[年份]
**期刊/会议**：[来源]

---

## 📌 三句话概括
[步骤1输出]

[步骤2输出]

## 📂 章节结构
[步骤3输出]

## ⭐ 核心创新点
[步骤4输出]

## 🏷️ 关键词图谱
[步骤5输出]

[步骤6输出]

---

**是否值得精读**：[是/否/待定]
**理由**：[简要说明判断依据]

```

---

## 注意事项

- 泛读追求速度，每个步骤不要过于深入，抓住核心即可
- 如果论文较长，重点关注摘要、引言、结论和图表，方法和结果部分可以略读
- 泛读的最终目的是做出判断：这篇论文值不值得花更多时间精读
