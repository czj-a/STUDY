> **语言要求：所有输出内容必须使用中文。** 包括标题、分析、总结、评价等全部文字输出。论文中的专业术语首次出现时用「中文（English）」格式标注，后续可直接使用中文。图表编号、公式、参考文献等学术规范内容保持原文格式。

# 论文精读 — 深度分析（14步，约30-40分钟）

## 适用场景

- 与课题方向相关的重要文献，需要真正理解并记住
- 文献综述的前期准备工作
- 需要评估论文质量并形成自己判断的场合

## 使用方式

用户提供论文 PDF 文件或完整的论文内容。然后依次执行以下 14 个步骤，分为四个阶段。

---

## 第一阶段：快速概览（步骤 1-6）

### 步骤 1：三句话概括

用**三句话**概括论文的核心主题、研究方法和主要结论。

```
📌 三句话概括：
1. [研究主题与目的]
2. [研究方法]
3. [核心发现/结论]
```

### 步骤 2：一句话检验

用**一句话**向非专业读者介绍这篇论文。

```
💡 一句话：[通俗概括]
```

### 步骤 3：章节结构

列出主要章节和小节标题，简要说明各章节内容。

```
📂 章节结构：[层级列表]
```

### 步骤 4：核心创新点

指出 1-3 个最核心的创新点或贡献。

```
⭐ 核心创新点：[列表]
```

### 步骤 5：关键词图谱

列出 5-10 个关键词及其在论文中的重要性。

```
🏷️ 关键词图谱：[关键词 + 解释]
```

### 步骤 6：图表速览

**第一步：整理全部图表名称。** 逐一列出论文中所有图表的编号和完整标题，按出现顺序排列，并标注类型（图/表）和所在页码或章节。

**第二步：重要性排序。** 将全部图表按重要性重新排序，对排名前 3 的图表描述各自传达的核心信息。

**第三步：故事线判断。** 回答：仅通过看这些图表，能否还原出这篇论文的主要故事线？

```
📊 图表速览：

一、图表名称清单：
| 编号 | 类型 | 标题 | 所在章节/页码 |
|------|------|------|--------------|
| Fig. 1 | 图 | [完整标题] | [章节/页码] |
| Fig. 2 | 图 | [完整标题] | [章节/页码] |
| Table 1 | 表 | [完整标题] | [章节/页码] |
| ... | ... | ... | ... |

二、重要性排序（Top 3）：
1. [图表编号+标题] — [核心信息]
2. [图表编号+标题] — [核心信息]
3. [图表编号+标题] — [核心信息]

三、故事线判断：
能否通过图表还原故事线：[是/否，简要说明]
```

---

## 第二阶段：逐章深入拆解（步骤 7-11）

### 步骤 7：引言拆解

详细解读引言部分，回答：
- 这篇论文**试图解决什么问题**？
- 论文**背景**是什么？作者是如何**铺垫**研究问题的？
- 引言**明确提出的研究问题**是什么？
- 作者是否**概括了论文的主要贡献**？提取出来。

```
📝 引言分析：
- 研究问题：[...]
- 背景铺垫：[...]
- 明确的研究问题：[...]
- 概括的主要贡献：[...]
```

### 步骤 8：方法拆解

详细解读方法部分，回答：
- 采用了**哪种或哪些研究方法**？
- 作者如何**具体执行**这些方法？（实验设计、数据收集、模型构建等）
- 提到了哪些**关键变量或指标**？
- 是否提到了**研究的局限性或潜在偏差**？
- 是否**解释了为什么选择这些方法**？

```
🔬 方法分析：
- 研究方法：[...]
- 执行步骤：[...]
- 关键变量/指标：[...]
- 作者提及的局限性：[...]
- 方法选择理由：[...]
```

### 步骤 9：数据与样本审视

专门评估数据来源与样本质量，回答：
- 数据**来源**是什么？来源是否**可靠且权威**？
- **样本量**是否充足？是否讨论了样本量确定依据？
- 是否存在**选择偏差、幸存者偏差或信息偏差**？
- 是否存在**数据缺失**？作者如何处理？
- 数据的**时间跨度和覆盖范围**是否足够？

```
📊 数据与样本评估：
- 数据来源：[...]
- 样本量：[...]
- 潜在偏差：[...]
- 数据缺失处理：[...]
- 覆盖范围评估：[...]
```

### 步骤 10：结果拆解

详细解读结果部分，回答：
- 呈现了哪些**主要研究结果**？
- 描述 2-3 个**关键图表**的主要信息。
- 是否**直接回答了引言中的研究问题**？
- 是否有**与预期不符的发现**？
- 是否说明了**统计显著性**？

```
📈 结果分析：
- 主要结果：[...]
- 关键图表解读：[...]
- 与研究问题的对应：[...]
- 意外发现：[...]
- 统计显著性：[...]
```

### 步骤 11：讨论与结论拆解

详细解读讨论和结论部分，回答：
- 作者如何**解释**主要研究结果？
- 是否与**之前的研究进行了比较**？哪些一致/不一致？
- 强调了哪些**重要意义**？
- 是否探讨了**研究的局限性**？
- 是否提出了**未来研究方向**？
- 结论的**核心论点**是什么？是否**呼应了引言的研究问题**？

```
💬 讨论与结论分析：
- 结果解释：[...]
- 与现有研究比较：[...]
- 研究意义：[...]
- 局限性：[...]
- 未来方向：[...]
- 核心论点与呼应关系：[...]
```

---

## 第三阶段：横向关联（步骤 12）

### 步骤 12：相关文献对比

基于论文主题，查找或回忆 2-3 篇相关论文，进行比较：
- 研究问题的异同
- 研究方法的不同
- 主要发现是否一致
- 本论文的突出差异或优势

```
🔗 文献对比：
| 维度 | 本论文 | 相关论文A | 相关论文B |
|------|--------|-----------|-----------|
| 研究问题 | ... | ... | ... |
| 研究方法 | ... | ... | ... |
| 主要发现 | ... | ... | ... |
| 优势/差异 | ... | ... | ... |
```

---

## 第四阶段：知识巩固（步骤 13-14）

### 步骤 13：一页纸总结

用一页纸的篇幅总结论文要点，假设要向一位**对这个领域不太了解的同事**介绍这篇论文。包含：研究背景、研究方法、数据来源、主要发现、重要意义。

```
📄 一页纸总结：

**这篇论文做了什么**：[1-2句]

**为什么重要**：[1-2句]

**怎么做的**：[方法简述]

**发现了什么**：[核心结果，2-3条]

**意味着什么**：[意义和应用]
```

### 步骤 14：应用场景

设想 2-3 个可能的应用场景，说明如何将论文的研究成果应用到实际中。

```
🎯 应用场景：

场景1：[场景描述]
- 如何应用：[...]
- 预期效果：[...]

场景2：[场景描述]
- 如何应用：[...]
- 预期效果：[...]

场景3：[场景描述]（如有）
- 如何应用：[...]
- 预期效果：[...]
```

## 输出方式

- 默认直接在对话中完整展示全部分析，不生成或保存 Markdown、Word、PDF 等报告文件。
- 不能用报告链接、附件或简短摘要替代完整的对话正文；全部 14 步、一页纸总结及应用场景也必须在对话中展示。
- 内容较长时，按阶段分段连续展示，不因篇幅而省略必需模块，也不改为文件交付。
- 仅当用户明确要求导出或保存时，才生成其要求的报告文件。
- 阅读论文所需的文本提取、页面渲染等中间文件不属于报告文件；需要落盘时遵循用户指定的中间文件目录。

## 注意事项

- 精读需要逐章仔细阅读，不要跳过细节
- 对于方法和数据部分，保持批判性思维，注意潜在偏差
- 文献对比环节如果无法联网检索，可以基于论文引用列表中的相关工作进行对比
- 一页纸总结是最重要的输出，确保语言通俗、逻辑清晰
